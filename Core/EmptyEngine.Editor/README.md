# EmptyEngine.Editor

EmptyEngine is an editor-only game engine with no runtime implementation of its own.

This package is the EmptyEngine editor itself. It contains the web UI you open in a browser (hierarchy, inspector, build), scene synchronization with the runtime, asset import and saving, undo/redo, and an HTTP API for reading and writing editor state from outside.

It also contains the abstractions for plugging in importers, serializers, inspectors, and distribution builds (`IAssetImporter`, `ISceneArtifactStore`, `IDistributionBuilder`, and so on).

Reference it from the editor-side project. The editor-side project is generated by EmptyEngine.Host, so normally you only need to add the reference to the targets file specified by `editorProps` in the project manifest (`*.emptyengine`).

That targets file must declare `AssetsPath` (the absolute path to the source assets). If you declare distribution builds, also declare `DistributionBuild` items and `BuildWorkingPath`.
