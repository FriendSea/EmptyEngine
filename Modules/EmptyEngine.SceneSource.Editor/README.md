# EmptyEngine.SceneSource.Editor

EmptyEngine is an editor-only game engine with no runtime implementation of its own. This package is part of an example .NET implementation of a runtime for use with EmptyEngine.

Importers for JSON source assets. They import scenes (`.scene`), nested prefabs, prefab variants, and self-describing assets of any type identified by type name (`.asset`), and write edits back to the source files.
