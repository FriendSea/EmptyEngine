# EmptyEngine.Serialization

EmptyEngine is an editor-only game engine with no runtime implementation of its own. This package is part of an example .NET implementation of a runtime for use with EmptyEngine.

Serialization for assets and scenes. It contains the per-type serializer table, instance creation and cloning, and asset resolution from artifacts. The storage format is MessagePack. The serializer code is generated by EmptyEngine.Serialization.Generator.
