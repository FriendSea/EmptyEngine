# DotnetRuntimeSample

[English](README.md) | 日本語

EmptyEngineに接続可能なランタイムの.NET実装例です。

## 使っているモジュール

このサンプルはModules以下にあるランタイム実装例を組み合わせて利用しています。
Unity同様のGameObjectとコンポーネントを持ち、それらで構成される単位をシーンとしてロードします。

## エディタ向けモジュール参照

各ランタイムモジュールには、対になるエディタ向けモジュールが存在する場合があります。
`EditorHalves.targets`ではランタイム向けモジュールのメタデータが定義するエディタパッケージの参照を追加しています。

## DIコンテナの利用

シーン表現も含め、ゲーム内で状態を持つ要素はすべてサービスとして1つのDIコンテナに登録されます。  
このコンテナはPlay/Editの切り替えのたびに丸ごと破棄/生成されます。  
このため、個々の状態を巻き戻す処理や、その検証は不要です。  

コンポーネント/アセットから各サービスへの参照はコンストラクタ経由で注入されます。

Window関連リソースのみ作り直しができないため、コンテナの管理外です。
Window位置やサイズなどの状態はPlay/Editを跨いで引き継がれます。
